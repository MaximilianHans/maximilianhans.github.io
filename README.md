# Maximilian Hans website

Replace the root `index.html`, `style.css`, and `script.js` with these files. Keep the existing `fonts/`, `images/`, and `pdfs/` folders. The page expects the existing image at `images/NetleyAbbey_cropped.png`, the favicon at `images/favicon.ico`, Calluna at `fonts/calluna-regular.ttf`, and the seminar schedule at `pdfs/Infinity_Categories_Seminar.pdf`.

Typography uses the site's existing Calluna font (`fonts/calluna-regular.ttf`) throughout. The compact responsive rules are optimised for phone widths down to 320px.

The final type scale is deliberately compact: 14px base text on desktop, 14px introductory text on phones, and 13px for dense cards and teaching lists.

Section boundaries use a distinct mellow-blue gradient rule. Paper, reading-group and teaching boxes have been removed, and external links are no longer underlined.

MathJax 4 is enabled with dollar-delimited inline mathematics. For example, writing `$\\infty$` in `index.html` renders the infinity symbol. Escape literal currency dollar signs as `\\$`.

The homepage introduction has compact vertical spacing: 46px below the navigation on desktop and 34px on mobile, with the first section boundary following closely after the introduction and photograph.

The two research projects are numbered `01` and `02`, matching the numbering style of the Notes list.
